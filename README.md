# Clocks

World clock, countdown timer and stopwatch in one terminal app. Fully offline, zero setup.

## Run

```
bash app-store.sh install
bash app-store.sh run
```

- `1` world clock: eleven zones from Chicago to Auckland, live.
- `2` timer: `T` sets the minutes (decimals fine, `0.5` is 30 seconds), Space starts and pauses, `R` resets. Beeps when time is up.
- `3` stopwatch: Space starts and stops, `L` marks a lap (split and total), `R` resets.

## Languages

Works with the Translations app: pick a language there and the labels switch (English, Espanol, Francais, Deutsch). With no Translations app installed it runs in English as usual.
